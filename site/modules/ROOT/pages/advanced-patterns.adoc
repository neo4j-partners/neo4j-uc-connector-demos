= Advanced Patterns
:description: Advanced Databricks notebooks for Neo4j metadata synchronization, additional federated queries, and performance diagnostics

The `advanced-patterns/` notebooks build on the four-step tutorial in `getting-started/`. Run the getting-started notebooks first so the aircraft digital twin graph, UC Volume data, Databricks secret scope, and Neo4j UC JDBC connection already exist.

The advanced federated query notebook uses `remote_query()` and does not require the Neo4j Spark Connector. Install the Neo4j Spark Connector only if you run the optional Spark Connector diagnostic cells in the performance notebook:

[source,text]
----
org.neo4j:neo4j-connector-apache-spark_2.12:5.4.0_for_spark_3
----

Install the Neo4j Python driver for metadata sync:

[source,bash]
----
pip install neo4j
----

== Connector and Secrets

Download the latest Neo4j JDBC Lakehouse Federation Connector from the https://github.com/neo4j-labs/neo4j-unity-catalog-connector/tags[neo4j-unity-catalog-connector releases] and upload it to a UC Volume. The path is referenced by `JDBC_JAR_PATH` in the repo-root `.env`.

Secrets are provisioned from `.env`:

[source,bash]
----
cp .env.sample .env
./create_secrets.sh
----

`create_secrets.sh` stores the Neo4j credentials plus shared UC, JDBC, and `LAKEHOUSE_SCHEMA` settings in the secret scope named by `DATABRICKS_SECRET_SCOPE`.
